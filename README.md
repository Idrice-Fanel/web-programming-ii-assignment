
# Web Programming II Assignment

## Contact Form Using PHP and MySQL

### 1. Create index.php
Create an HTML form containing Name, Email, and Contact fields. The form must send data to submit.php using the POST method.

### 2. Create submit.php
Retrieve the submitted POST data and save it to the database.

### 3. Create the database
Database name: Contacts

Table name: contact

Fields:
- id
- name
- email
- contact

### 4. Save the submitted data
Use PHP to retrieve the form data and insert it into the contact table in MySQL.

- HTML
- PHP
- MySQL
